## 3. Персональные данные, которые обрабатываются

При использовании Сервиса могут обрабатываться следующие данные:
- Telegram ID, username, имя аккаунта (передаются автоматически при взаимодействии с ботом);
- данные о заказах (ID заказа, сумма, дата и статус оплаты, вид приобретённой услуги);
- сведения, направленные Пользователем добровольно в переписке с администраторами (жалобы, обращения по возврату, отзывы, оценки);
- технические данные (IP-адрес, данные cookie при посещении сайта, если применимо);

Персональные данные обрабатываются в целях:

- модерации сообщества (обработка жалоб, нарушений, отзывов);
- информирования Пользователя о статусе заказа/услуги;
